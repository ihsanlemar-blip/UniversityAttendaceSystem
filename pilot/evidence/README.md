# Milestone 19 Acceptance Evidence Directory

This directory houses structured, anonymized, and committed evidence artifacts for Milestone 19 field acceptance across physical campus environments.

## Committed Evidence Guidelines
- **Allowed:**
  - Anonymized result tables and sign-off checklists
  - Redacted server log excerpts with UUIDs
  - Photographic metadata summaries (e.g. scan distance vs lighting matrix)
  - BLE signal RSSI distribution logs with anonymized client IDs
- **Strictly Prohibited:**
  - Real student personal identifiable information (PII)
  - Real user passwords, private keys, or session JWTs
  - Raw unredacted packet captures (.pcap)
  - Unsanitized production database dumps
